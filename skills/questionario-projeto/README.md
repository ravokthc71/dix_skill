# Questionário de Projeto

Template padrão para criar questionários de projeto no cofre Obsidian.

## Estrutura

| Seção | Descrição |
|-------|-----------|
| `Objetivo` | Defina o propósito principal do projeto. |
| `Próximos passos` | Lista de tarefas iniciais com checklists (`- [ ]`). |
| `Notas` | Espaço para anotações complementares. |
| `Referências` | Links para documentos, pesquisas ou materiais de apoio. |

## Como usar

1. Copie o template para uma nova nota em `20_Projetos/`.
2. Preencha as seções com as informações específicas do seu projeto.
3. Use o frontmatter para definir `tipo: projeto` e o status.

## Exemplo de frontmatter

```yaml
---
tipo: projeto
criado: 2026-11-01
atualizado: 2026-11-01
status: ativo
tags: [seu, tags, aqui]
---
```

> **Dica:** Adicione wikilinks para notas relacionadas (`[[Nota]]`) e referências externas (`[texto](url)`).
