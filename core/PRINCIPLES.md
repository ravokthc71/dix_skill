# Princípios Arquiteturais do DIIX

1. Universalidade — não depender exclusivamente de OpenCode.
2. Modularidade — instalar e utilizar componentes individualmente.
3. Portabilidade — funcionar em Windows, Linux e cloud.
4. Progressive Disclosure — carregar conhecimento sob demanda.
5. Provider Agnostic — não depender apenas de OpenRouter ou 9Router.
6. Agent Agnostic — não depender de um único agente.
7. Automação verificável — entradas, saídas, validações, erros tratados.
8. Segurança por padrão — segredos fora do Git, permissões explícitas.
9. Observabilidade — registrar operações, erros, latência, consumo.
10. Evolução controlada — versionamento, testes, documentação, compatibilidade.
