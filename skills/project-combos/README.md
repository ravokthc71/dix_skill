# Skills - Combinações por Tipo de Projeto

Esta pasta sugere **combinações de modelos e instruções** para diferentes cenários de desenvolvimento.

| Tipo de projeto | Modelo sugerido (free) | Modelo sugerido (pago) | Uso principal |
|-----------------|------------------------|------------------------|---------------|
| Frontend / UI | modelo leve gratuito | modelo médio | geração de componentes, CSS, acessibilidade |
| Backend / API | modelo médio gratuito | modelo capaz | design de endpoints, documentação, integrações |
| Dados / SQL | modelo médio gratuito | modelo capaz | consultas SQL, modelagem, ETL |
| DevOps / Infra | modelo leve gratuito | modelo médio | Docker, CI/CD, scripts de deploy |
| Escrita / Docs | modelo leve gratuito | modelo médio | README, documentação, tradução |
| Arquitetura | - | modelo mais capaz | decisões técnicas, padrões de design |

## Como usar

1. Identifique o tipo do seu projeto na tabela acima.
2. Escolha o modelo adequado ao orçamento (free ou pago).
3. Aplique a skill/instrução correspondente desta pasta.

> Adicione combinações específicas conforme você ganha experiência com cada LLM.
